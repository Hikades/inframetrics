# InfraMetrics · Landing page (HCI for UX Design – TB2, Keros Group)

Monitoreo y mantenimiento predictivo de maquinaria pesada. Aplicación de una sola página en HTML, CSS y JavaScript (sin librerías).

## Cómo usarla
- Abre `index.html` en el navegador o la URL de GitHub Pages.
- Cuenta demo: `demo@inframetrics.com` / `Demo1234`
- Código para restablecer contraseña: `123456`

## Estructura
- `index.html`: estructura, pantallas de acceso, menú y diálogos.
- `styles.css`: guía de estilos (paleta, tipografía) y diseño responsive.
- `app.js`: datos simulados, rutas, vistas, validaciones e interacciones.
- `img/`: fotografías de la flota (WebP).
