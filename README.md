# InfraMetrics · Landing Page
Proyecto HCI for UX Design (1ASI0385) · TB2 · Keros Group

Monitoreo y mantenimiento predictivo de maquinaria pesada. Aplicación responsive de una sola página en HTML, CSS y JavaScript puros (sin librerías).

## Cómo usarla
- Abrir `index.html` en el navegador o la URL de GitHub Pages https://hikades.github.io/inframetrics/.
- Cuenta demo: `demo@inframetrics.com` / `Demo1234`
- Código de verificación para restablecer contraseña: `123456`

## Estructura del repositorio
```
/
├── index.html            Estructura, accesos, menú y diálogos
├── README.md
├── assets/
│   ├── css/styles.css    Guía de estilos (paleta, tipografía) y diseño responsive
│   ├── js/app.js         Datos simulados, rutas, vistas, validaciones e interacciones
│   └── img/              Fotografías de la flota (WebP)
└── docs/
    └── pruebas/          Resultados de las pruebas de aceptación (31 casos)
```
